TELEGRAM AI ROUTER BOT — ИТОГ И ПОЛНАЯ ИНСТРУКЦИЯ
==================================================

Репозиторий:
https://github.com/Yur1Mat/telegram-ai-router-bot

Что создано
------------
Готов приватный Telegram-бот, в котором можно сохранить API-ключи и
переключаться между OpenAI, Claude (Anthropic), DeepSeek и произвольным
OpenAI-совместимым API. Настройки провайдера, модели, endpoint и системной
инструкции меняются командами прямо внутри Telegram.

Безопасность:
- бот отвечает только Telegram ID из ADMIN_USER_IDS;
- API-ключи хранятся в SQLite в зашифрованном виде (Fernet);
- сообщение с командой /setkey бот старается сразу удалить;
- файл .env и папка data исключены из Git;
- OpenAI Responses API вызывается с store=false.

Встроенные настройки по умолчанию на 29.08.2026:
- OpenAI: gpt-5.6-luna;
- Claude: claude-sonnet-5;
- DeepSeek: deepseek-v4-flash.

Любую модель можно заменить командой /model без изменения кода.


1. СОЗДАНИЕ TELEGRAM-БОТА
-------------------------
1) Откройте в Telegram официального бота @BotFather:
   https://t.me/BotFather
2) Отправьте команду /newbot.
3) Введите отображаемое имя бота.
4) Введите уникальный username, который заканчивается на bot.
5) Скопируйте токен вида 123456:ABC... и никому его не передавайте.
6) Узнайте свой числовой Telegram ID через @userinfobot:
   https://t.me/userinfobot


2. УСТАНОВКА НА WINDOWS
-----------------------
Установите Git и Python 3.11 или новее, затем выполните в PowerShell:

git clone https://github.com/Yur1Mat/telegram-ai-router-bot.git
cd telegram-ai-router-bot
Copy-Item .env.example .env
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

Последняя команда выведет ключ шифрования. Скопируйте его.

Откройте файл .env и заполните:

TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_USER_IDS=ваш_числовой_Telegram_ID
ENCRYPTION_KEY=сгенерированный_ключ_Fernet
DATA_DIR=./data
LOG_LEVEL=INFO

Для нескольких пользователей перечислите ID через запятую:
ADMIN_USER_IDS=123456789,987654321

Запуск:

python -m bot

Окно PowerShell должно оставаться открытым. Для постоянной работы лучше
использовать VPS или Docker.


3. ЗАПУСК ЧЕРЕЗ DOCKER
----------------------
После заполнения .env выполните:

docker compose up -d --build

Просмотр логов:

docker compose logs -f

Остановка:

docker compose down

База данных сохраняется на компьютере в папке data.


4. НАСТРОЙКА API В TELEGRAM
---------------------------
Откройте созданного бота и отправьте /start.

Добавление ключей:

/setkey openai sk-...
/setkey anthropic sk-ant-...
/setkey deepseek sk-...

Выбор сервиса:

/providers

Нажмите кнопку OpenAI, Claude (Anthropic), DeepSeek или Custom API.
При переключении провайдера контекст очищается автоматически.

Полезные команды:

/providers             выбор провайдера
/model ИМЯ_МОДЕЛИ       смена модели
/endpoint HTTPS_URL     endpoint для Custom API
/system ТЕКСТ           системная инструкция модели
/status                 текущие настройки и наличие ключа
/clear                  очистить историю диалога
/help                   справка

Примеры смены модели:

/model gpt-5.6-luna
/model claude-sonnet-5
/model deepseek-v4-flash


5. ПОДКЛЮЧЕНИЕ ЛЮБОГО OPENAI-СОВМЕСТИМОГО API
---------------------------------------------
В Telegram:

1) Отправьте /providers и выберите Custom API.
2) Сохраните ключ:
   /setkey custom ВАШ_API_КЛЮЧ
3) Задайте базовый HTTPS URL, обычно заканчивающийся на /v1:
   /endpoint https://example.com/v1
4) Задайте точное имя модели:
   /model model-name
5) Отправьте обычное сообщение боту.

Custom API должен поддерживать OpenAI-совместимый метод:
POST {endpoint}/chat/completions


6. ГДЕ ПОЛУЧИТЬ API-КЛЮЧИ
-------------------------
OpenAI:    https://platform.openai.com/api-keys
Anthropic: https://console.anthropic.com/settings/keys
DeepSeek:  https://platform.deepseek.com/api_keys

Подписка ChatGPT Plus/Pro обычно не является балансом OpenAI API. Аналогично,
веб-подписка другого сервиса может не включать API. Проверьте биллинг в кабинете
конкретного API-провайдера.


7. ПРОВЕРКА ПРОЕКТА
-------------------
Из активированного виртуального окружения:

python -m unittest discover -s tests -v

Ожидаемый результат: 3 теста, статус OK.


8. ВАЖНЫЕ ЗАМЕЧАНИЯ
-------------------
- Никогда не коммитьте .env и папку data в GitHub.
- Не теряйте ENCRYPTION_KEY: без него сохранённые ключи не расшифровать.
- Если ENCRYPTION_KEY был заменён, удалите локальный data/bot.sqlite3 и заново
  добавьте API-ключи.
- Используйте /setkey только в личном чате с ботом.
- Названия и доступность моделей со временем меняются. Актуальное имя всегда
  можно задать через /model.
- Для круглосуточной работы разместите проект на VPS с Docker Compose.


9. КРАТКИЙ СЦЕНАРИЙ ПЕРВОГО ЗАПУСКА
-----------------------------------
1) Создать бота через @BotFather.
2) Клонировать репозиторий.
3) Создать .env и заполнить токен, Telegram ID и ENCRYPTION_KEY.
4) Запустить python -m bot или docker compose up -d --build.
5) В Telegram отправить /setkey openai ВАШ_КЛЮЧ.
6) Отправить /providers и выбрать OpenAI.
7) Написать боту обычное сообщение.

Проект протестирован локально: все 3 автоматических теста пройдены.
