# Telegram-бот добрых пожеланий

Два пожелания каждый день: **08:30 и 17:30 по Москве**.

Основной вариант — **Cloudflare Workers + закрытая база D1**. Компьютер можно выключать. GitHub хранит только исходники, отправка через GitHub Actions отключена.

- `/start` — подписаться; каждый пользователь подписывается самостоятельно.
- `/stop` — отключить рассылку.
- `/status` — проверить подписку.
- `/help` — справка.

С 15 сентября 2026 года используется новая база: 750 утренних и 750 вечерних пожеланий. Утром сначала идёт тёплый комплимент, вечером — только пожелание. Запаса хватает на 750 дней. При исчерпании база не зацикливается: её нужно пополнить. Все подписчики получают одинаковый текст для одного времени отправки.

На обычное личное сообщение, фото, стикер или аудиофайл бот случайно выбирает одну из 17 фраз владельца в `AUTO_REPLIES` (`cloudflare/content.mjs`). Для голосовых сообщений (`message.voice`) используется отдельный пул из 5 фраз `VOICE_REPLIES`. Голосовые не скачиваются и не распознаются. Каждый выбор независимый, поэтому возможны повторы. Это отдельные автоответы, они не добавляются к плановым пожеланиям. Команды, объятия и ожидание вопроса волшебному шару имеют приоритет: в режиме шара бот просит прислать вопрос текстом. Обычное сообщение не включает подписку автоматически.

[Инструкция по Cloudflare](cloudflare/README.md)

Python-версия в папке `bot` остаётся альтернативой для постоянного сервера/Docker. Не запускайте её одновременно с Cloudflare: Telegram допускает либо webhook, либо polling. Локальные экспериментальные файлы подписчиков никогда не должны публиковаться в GitHub.

## Проверки

Node.js 24:

```sh
node --test cloudflare/schedule.test.mjs cloudflare/worker.test.mjs cloudflare/content.test.mjs
```

Токен Telegram хранится только в Cloudflare Secrets или локальном `.env`, ID подписчиков — только в закрытой базе. Если токен стал известен посторонним, перевыпустите его через BotFather и обновите секрет.
