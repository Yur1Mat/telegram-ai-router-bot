# Telegram-бот добрых пожеланий

Два пожелания каждый день: **08:30 и 17:30 по Москве**.

Основной вариант — **Cloudflare Workers + закрытая база D1**. Компьютер можно выключать. GitHub хранит только исходники, отправка через GitHub Actions отключена.

- `/start` — подписаться; каждый пользователь подписывается самостоятельно.
- `/stop` — отключить рассылку.
- `/status` — проверить подписку.
- `/help` — справка.

Каталог содержит 2305 уникальных полных текстов: хватает более чем на 3 года при двух сообщениях в день. Тексты составлены из комбинаций пожеланий и дополнений, отдельные фразы повторяются. Все подписчики получают одинаковое пожелание для одного времени отправки.

[Инструкция по Cloudflare](cloudflare/README.md)

Python-версия в папке `bot` остаётся альтернативой для постоянного сервера/Docker. Не запускайте её одновременно с Cloudflare: Telegram допускает либо webhook, либо polling. Локальные экспериментальные файлы подписчиков никогда не должны публиковаться в GitHub.

## Проверки

Node.js 24:

```sh
node --test cloudflare/schedule.test.mjs cloudflare/worker.test.mjs
```

Токен Telegram хранится только в Cloudflare Secrets или локальном `.env`, ID подписчиков — только в закрытой базе. Если токен стал известен посторонним, перевыпустите его через BotFather и обновите секрет.
